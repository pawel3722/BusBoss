# BusBoss

Application for **designing, managing and analyzing public transport networks**.

The system allows users to create and modify transport infrastructure, define routes and stops, and manage the connections between them. It is designed to support the planning and development of urban public transport networks.

## Features

* designing public transport networks
* creating and managing stops
* creating and modifying bus routes
* defining connections between stops
* managing timetables and vehicle services
* visualizing the transport network
* editing existing network infrastructure
* analyzing network structure and connections

## Main workflow

```text
Create network
      ↓
Add stops and infrastructure
      ↓
Design routes
      ↓
Configure connections and services
      ↓
Analyze and modify network
```

## Technologies

* Qt
* C++

## Project

The project focuses on supporting the **planning and day-to-day management of urban public transport networks**, providing tools for both network design and subsequent modifications.
